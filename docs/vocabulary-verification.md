# DAY 01~05 단어 데이터 검증

## 원본의 한계

첨부된 `워드마스터 수능2000.pdf`는 25페이지 분량의 영어 단어 시험지입니다. DAY 01~05의 한글 **뜻 칸 200개가 모두 비어 있습니다.** 텍스트 추출과 원본 1~3페이지 이미지로 확인했습니다.

영어 단어, DAY, 행 번호는 등록했습니다. 원본에 없는 한글 뜻은 생성하거나 사전에서 보충하지 않았으며, 각 항목의 `meaning`은 `null`입니다. `src/data/vocabulary/source.json`의 `meaningStatus: "missing-in-source"`와 DAY별 `missingMeaningCount`로 별도 표시합니다. 한글 뜻을 포함한 완전한 데이터 등록 및 뜻 일치 검증은 미완료이며, 뜻이 수록된 원본이 필요합니다.

- 인쇄된 번호 1~40을 기준으로 각 DAY 순서를 유지했습니다.
- PDF 레이아웃 추출 결과와 JSON의 영어 철자 및 순서를 전수 비교했습니다.
- 별도로 PDF 텍스트 좌표에서 번호, 영어 칸, 뜻 칸을 찾아 200개 행을 다시 비교했습니다.
- PDF 1~3페이지 이미지를 열어 5개 DAY의 영단어와 비어 있는 뜻 칸을 검토했습니다.
- 고유 ID 200개와 영어 단어 200개에 중복이 없습니다. 영어 철자의 불확실한 항목은 발견되지 않았습니다.
- DAY 06은 3페이지 오른쪽에 있지만 이번 등록 범위에서 제외했습니다.
- 원본 파일 SHA-256과 페이지·열 정보는 `source.json`에 기록했습니다.

## 재검증

네트워크나 npm 의존성을 사용하지 않습니다. Python 3와 PDF 원본 비교용 Poppler의 `pdftotext`만 사용합니다.

```bash
python3 scripts/validate-vocabulary.py
python3 scripts/validate-vocabulary.py "/path/to/워드마스터 수능2000.pdf"
```

첫 명령은 JSON 구조·개수·ID·순서·중복·뜻 미수록 표시를 확인합니다. 두 번째 명령은 원본 해시와 PDF의 모든 해당 행을 추가로 대조합니다.

## 앱 연결 범위

`getDayVocabulary(day)`는 원본 순서의 읽기 전용 배열을 반환합니다. `getDayVocabularySummary(day)`는 단어 수, 데이터 존재 여부, 누락된 뜻 개수 및 뜻 완성 여부를 반환합니다. 신규 DAY JSON을 추가하고 `index.ts`의 매핑에 등록하면 확장할 수 있습니다.

학습 지도 DAY 배지에 DAY 01~05는 `40개 단어`, DAY 06~50은 `준비 중`으로 표시합니다. 단어 수 표시의 접근성 설명과 툴팁에도 뜻의 원본 미수록을 명시합니다. 데이터 등록 여부는 기존 잠금 상태와 독립적이며, 학습 기능이나 잠금 해제 동작을 변경하지 않았습니다.

기존 지도 경로, 노드, 레오 이미지, 화면 이동, 하단 메뉴 및 학습 상태 코드는 유지했습니다. npm 의존성이 설치되지 않아 `npm install`과 `npm run build`는 실행하지 않았습니다. 이번 검증은 데이터와 소스의 정적 검증입니다.
