# DAY 01 예문 학습 — 4단계

## 콘텐츠 출처 구분

3단계에서 추출한 200개 원본 단어 JSON, ID, DAY, 번호, 철자와 `meaning: null`은 변경하지 않았습니다. PDF의 뜻 칸이 비어 있다는 원본 검증 기록도 유지합니다.

이번 단계의 뜻은 일반적인 사전적 용법을 바탕으로 새로 작성한 학습용 요약입니다. 특정 사전 문구를 인용한 자료나 교재 원문으로 표시하지 않습니다. DAY 01의 40개 뜻은 `day01-learning-meanings.json`에서 원본 ID에 연결하고, 공용 `getDayVocabulary`가 학습용 뜻을 합쳐 제공합니다. DAY 02~05의 뜻은 여전히 `null`입니다.

`meaningOrigin: learning-authored`로 학습용 뜻을 구분하고, `sourceMissingMeaningCount`는 원본 PDF의 뜻 미수록 개수를 따로 유지합니다. 모든 뜻은 검토한 대표적 의미로 작성했으며, 불확실한 뜻을 확정한 항목은 없습니다. `object`는 이번 이야기에서 '물건'이라는 명사로 쓰이고, 동사의 뜻 '반대하다'와 구분하는 설명을 제공합니다.

영어 이야기와 한글 해석도 앱을 위해 새로 작성한 콘텐츠입니다. 학습 화면에서 출처 구분 문구를 항상 표시합니다.

## 세트 구성

| 세트 | 원본 순서 | 단어 |

| 01 | 1~5 | provide, develop, cultural, inform, social |
| 02 | 6~10 | improve, individual, require, volunteer, behave |
| 03 | 11~15 | amount, relationship, employ, attitude, research |
| 04 | 16~20 | audience, challenge, influence, material, opportunity |
| 05 | 21~25 | environment, expense, local, involve, stress |
| 06 | 26~30 | therefore, contain, average, ride, encourage |
| 07 | 31~35 | determine, international, consume, impress, object |

레오의 독서 모임, 책 나눔, 박람회를 배경으로 세트마다 짧은 연결 문장을 제공합니다. 타깃 단어는 원형 그대로 문장에 등장하고 단어 경계로 매칭해 강조합니다. 대소문자를 구분하지 않고 원문의 대소문자는 보존합니다.

## 동작 및 저장

- 강조한 단어를 누르면 뜻이 나타납니다. 단어 5개의 뜻과 발음은 펼침 목록에서도 확인합니다.
- 해석은 처음에는 숨겨져 있습니다. 세트를 이동하면 해석, 선택 단어, 카드 스크롤과 뜻 목록을 초기화하고 재생 중인 음성을 중지합니다.
- Web Speech API는 클릭 핸들러에서 동기적으로 호출합니다. 영어 음성이 있으면 우선 선택하고, 아직 음성 목록이 비어 있으면 `en-US` 언어로 브라우저 기본 음성을 사용합니다. 음성 목록은 매 재생 시 다시 조회합니다.
- 단어·전체 이야기는 한 번에 하나씩 재생합니다. 중지 버튼 및 학습 화면을 떠날 때 기존 음성을 취소합니다. 미지원·음성 사용 불가·재생 실패를 안내합니다.
- 이전/다음/번호 버튼으로 세트를 자유롭게 이동할 수 있습니다. 이동만으로 완료 처리하지 않고 각 세트의 완료 버튼으로 기록합니다.
- localStorage 키: `word-master-adventure:day01-sentences:v1`. 저장 형식은 버전과 완료한 세트 ID 목록입니다. 8개 고유 세트 모두 완료해야 DAY 01 예문 완료가 됩니다.
- 다시 들어오면 첫 미완료 세트를 표시하고, 모두 완료한 경우 첫 세트부터 복습합니다. 깨진 JSON·알 수 없는 버전은 안전하게 빈 기록으로 시작하고, 중복·알 수 없는 세트 ID는 제외합니다.
- 저장 권한·용량 문제는 화면에 표시하며, 현재 메모리의 학습 진행은 유지합니다. 이 경우 새로고침 후 유지된다고 안내하지 않고, 완료 버튼으로 저장을 다시 시도할 수 있습니다.
- DAY 01 예문 완료는 지도에서 금색 별과 체크로 표시하며 DAY 상세 진행률은 1/2 단계(50%)입니다. 퍼즐이 준비되지 않았으므로 DAY 전체 완료나 XP 보상으로 처리하지 않습니다.
- DAY 02~50 예문과 모든 퍼즐은 콘텐츠가 준비되지 않아 계속 잠겨 있습니다.

## 모바일 구성

기존 크림색 화면, 연두색 입체 버튼, 게코 원본 이미지 및 고정 하단 메뉴를 유지합니다. 영어 이야기/해석은 카드 안에서 세로 스크롤하며, 뜻 목록은 펼침형으로 공간을 절약합니다. 학습 버튼은 문서 흐름에 배치하고 기존 하단 Safe Area 여백을 유지합니다. 좁은 화면에서는 세트 번호를 4개씩 두 줄로 배치해 최소 44px 터치 영역을 확보합니다.

## 검증

실행한 명령:

```bash
python3 scripts/validate-vocabulary.py
python3 scripts/validate-day01-lessons.py
node --experimental-strip-types scripts/day01-progress.test.mjs
```

- 200개 원본 데이터의 구조·고유 ID·순서 검증 통과. 작업 전후 SHA-256으로 5개 JSON과 게코 이미지의 변경 없음 확인.
- 새 뜻 40개와 원본 ID의 일대일 대응 검증 통과. 8개 세트에 연속된 5개 단어씩 정확히 한 번 배정되며 해당 영어 이야기에 모두 등장함을 검증.
- 뜻과 문장 문맥, 한글 해석을 수동 검토. DAY 02~05 학습 콘텐츠는 작성하지 않음.
- 저장 로직 5개 테스트 통과: 손상된 데이터/버전 처리, 잘못된 ID와 중복 제거, 8개 모두 완료 필요, 부분·전체 진행의 저장 후 새 로딩, 저장소 권한·용량 오류 전달.

프로젝트 의존성이 없어 npm 설치 및 빌드는 실행하지 않았습니다. React 앱의 실제 브라우저 실행, 실제 기기 음성 재생 및 모바일 화면 시각 검증은 수행하지 못했습니다. 저장 테스트는 메모리 기반 Storage 대역을 사용한 로직 검증이며 실제 브라우저 localStorage 검증과 구분합니다.
