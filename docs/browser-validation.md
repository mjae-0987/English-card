# 프로덕션 빌드 및 모바일 브라우저 검증

## 빌드

2026-10-24에 네트워크 접근 권한과 쓰기 가능한 `/tmp` 캐시를 사용한 의존성 설치가 21초에 완료됐습니다. 자동 네트워크 재시도는 0회, 명령 전체 제한은 180초로 설정했습니다. 설치를 무한 반복하지 않았습니다.

- Node.js 24.19.0 / npm 11.9.0 (배포 환경 설정은 지원되는 Node 22.12 이상도 호환)
- 실제 설치 결과로 생성한 package-lock.json 포함
- `npm run build`: TypeScript 검사 및 Vite 7.3.7 프로덕션 빌드 성공
- 정적 출력: `dist/index.html`, `dist/assets/`, 원본 게코 이미지, 파비콘

## 실제 브라우저 실행

빌드 결과를 Vite preview로 로컬 제공하고, 환경에 이미 설치된 Playwright와 Chromium으로 실행했습니다. 프로젝트에 브라우저 자동화 라이브러리를 추가하지 않았습니다. 브라우저 런타임 예외는 발견되지 않았습니다.

검증을 통과한 동작:

1. 지도 50개 DAY / 100개 노드, 마스코트 정상 로딩, 초기 잠금 상태
2. 하단 메뉴 이동, 예문 미완료 시 퍼즐 직접 경로도 잠금
3. 예문 8세트와 각 세트의 단어 강조, 단어 터치 시 뜻, 5개 단어 목록
4. 한글 해석 보기/숨기기 및 카드 스크롤
5. 단어/전체 이야기 발음 버튼의 호출 연결과 미지원 안내
6. UI 버튼으로 예문 8세트 완료 후 실제 localStorage 저장 및 새로고침 복원
7. 지도에서 퍼즐 잠금 해제와 퍼즐 화면 이동
8. 브라우저 키보드 이벤트로 알파벳 입력·자동 다음 칸·Backspace·방향 전환
9. 선택 단어 채점, 두 단계 힌트, 전체 채점과 오답 기록
10. 미완료 퍼즐 입력·힌트 사용 기록의 새로고침 복원
11. 모든 단어를 UI 입력창으로 채운 뒤 완료 화면과 날짜·오답·힌트 기록 저장
12. 새 퍼즐 생성 후 기존 완료 기록 보존, DAY 01 전체 완료, DAY 02 잠금 유지
13. 320/375/390/430px에서 지도·DAY 상세·예문·퍼즐·단어장·기록의 6개 화면에 가로 스크롤 없음

구조화된 검사 결과는 [browser-validation.json](browser-validation.json)에 있습니다.

## 검증 범위의 한계

모든 화면 검증의 실제 엔진은 Chromium입니다. Android 및 iPhone의 화면·터치·일부 user-agent 설정을 에뮬레이션했지만, Safari 엔진 또는 Android/iPhone 실기기에서 실행한 결과는 아닙니다. 물리 키보드 이벤트는 검증했고 모바일 OS의 실제 소프트 키보드 열림·레이아웃 및 iOS 고유 이벤트는 별도 확인이 필요합니다.

음성은 브라우저 API 대역으로 버튼의 텍스트·언어 전달과 미지원 안내를 검사했습니다. 실제 영어 음성 출력과 기기별 음성 엔진은 검증하지 않았습니다.

검증 대상은 로컬 프로덕션 빌드입니다. Cloudflare에 배포가 성공했거나 공개 URL에서 정상 동작했다고 표시하지 않습니다.

## Cloudflare 직접 업로드

GitHub 연동이 계속 인식되지 않는 동안 기존 Direct Upload 프로젝트를 사용할 수 있도록 `deploy/word-master-adventure-dist.zip`을 생성했습니다. ZIP의 루트에 index.html이 있고, 소스코드나 node_modules는 포함하지 않습니다. Cloudflare의 Upload assets에 ZIP을 업로드해 첫 배포를 실행한 다음 공개 pages.dev 주소에서 다시 검증합니다. GitHub 자동 배포 연결은 이 직접 업로드와 별개이며 아직 해결되지 않았습니다.
