# 6단계 및 UI·음성 개선 검증

2026-10-27. 사용자의 ‘둘 다’ 답변에 따라 DAY 02~05 콘텐츠 확장과 UI·음성 개선을 함께 반영했습니다.

## 보존 및 구현

- 원본 DAY 01~05 JSON 5개, 영어 200개·ID·DAY·순서·null 뜻 필드 유지. 원본 PDF의 해시·텍스트 레이아웃·좌표 비교를 다시 통과했습니다.
- 기존 DAY 01 이야기 8개·학습용 뜻 40개 및 마스코트 원본 파일 유지. 작업 전후 SHA-256 대조를 수행했습니다.
- DAY 02~05의 학습용 뜻 160개와 영어 이야기/번역 32세트를 별도 JSON에 추가. 교재 공식 뜻·예문으로 표시하지 않습니다.
- 공통 예문 화면/퍼즐/생성기 사용. 각 DAY는 원본 40개 단어를 연속 5개씩 다루며 DAY별 단어를 혼합하지 않습니다.
- 예문 8세트 → 해당 DAY 퍼즐 → DAY 완료 → 다음 DAY 순서. DAY 06~50은 잠금/준비 중 유지.
- 별표와 오답/복습은 독립 저장. 퍼즐 오답은 새 퍼즐에서도 보존하고, 복습 성공 뒤에도 원래 오답 이력을 삭제하지 않습니다.
- DAY별 저장 키를 확장하되 기존 DAY 01 키/형식은 그대로 사용. 구버전 퍼즐의 오답 이력을 복습 목록에 합칩니다.
- 마지막 DAY·학습 화면·세트 위치를 기록하고 지도/기록에서 이어서 학습합니다.
- 단어장/별표/복습/기록/음성 설정 화면을 연결했습니다. 퍼즐 탭은 DAY 선택 후 완료까지 선택 DAY를 유지합니다.

## UI 및 음성

학습 화면의 ‘새로 작성한 학습용 뜻·예문 · 교재 원문 아님’, 퍼즐의 출처 반복 문구, 지도 title/aria-label의 원본·뜻 등록 검증 설명, 자동 음성 미지원 안내, 단어장/기록의 개발 예정 화면을 제거했습니다. 출처는 README와 JSON 메타데이터에 유지합니다. 법적 고지를 삭제하지 않았고, 실제 저장/재생 오류 안내는 유지합니다.

주요 색·모서리·그림자·간격·터치 크기를 CSS 변수로 정리했습니다. 지도 경로를 DAY 사이로 연결하고 현재 노드 옆에 기존 마스코트, 완료 DAY에 체크, 이어서 학습 버튼을 표시합니다. 예문/뜻/힌트의 글자 크기와 대비를 높이고 버튼과 카드를 통일했습니다. Safe Area/100dvh/고정 메뉴를 유지하며, 가상 키보드가 감지되면 하단 메뉴를 숨깁니다. 격자 칸은 화면 안에 맞추고 입력/주요 조작에는 별도의 44px 이상 터치 버튼을 제공합니다.

음성은 실제 Web Speech API에 연결합니다. 사용자 클릭에서 `speak`를 호출하며 영어 음성만 선택합니다. en-US 우선, `voiceschanged`, 0.75/1/1.15 속도, 선택 음성/속도 저장, 정지 아이콘, 이전 재생 취소, 세트/경로/창 이동 시 중지, 콜백 경합 방지 및 실제 오류 시 간단한 메시지를 구현했습니다. 이야기의 영어 원문을 문장 순서대로 읽고 한국어 해석은 제외합니다.

## 실행한 검사

- `python3 scripts/validate-vocabulary.py <원본 PDF>`: PDF 해시, 레이아웃 추출, 좌표 추출, 200개 원본 단어 및 빈 뜻 칸 일치 통과.
- `python3 scripts/validate-day01-lessons.py`: 기존 DAY 01 콘텐츠 검증 통과.
- `npm test`: 기존 진행/퍼즐 검사 + DAY 01~05 데이터, 500개 시드 퍼즐, 저장 복원, 별표 독립성, 복습 이력, 잠금 순서, 음성 제어 로직 검사 통과.
- `npm run test:render`: React 서버 렌더링으로 40개 학습 세트·5개 완료 화면·단어 카드 200개·복습·별표·기록·설정·잠금 화면과 DAY 01 기존 키 보존 검사 통과.
- `npm run build`: TypeScript 및 Vite 7.3.7 프로덕션 빌드 통과. 기존 node_modules를 사용했으며 npm 설치를 반복하지 않았습니다.

음성 제어 로직 검사는 테스트용 합성기 객체에 실제 프로덕션 SpeechPlayer를 연결해 정확한 영어 텍스트/순서/속도/음성 선택, 취소/교체/완료/오류 및 오래된 콜백 무시를 검사했습니다. 실제 소리 출력 결과를 뜻하지 않습니다.

## 미검증 및 배포 제한

이번 변경의 브라우저 자동화는 실행 권한 요청 취소 뒤, 외부 네트워크를 사용하지 않는 로컬 파일 전달 방식으로도 시도했으나 Chromium 자체가 샌드박스의 `setsockopt` / `shutdown: Operation not permitted` 오류로 시작하지 못했습니다. 테스트가 브라우저 실행 전에 중단됐으며 이번 버전의 모바일 화면 폭·클리핑·버튼 겹침·실제 키보드·클릭 흐름을 검증 완료로 표시하지 않습니다.

실제 Android Chrome/iPhone Safari의 소리, 장치별 영어 목소리, 소프트 키보드와 새로고침 동작은 별도 검증이 필요합니다. 이전 `browser-validation.md/json`은 DAY 01만 있던 5단계의 결과입니다.

기존 공개 주소 `https://english-cq9.pages.dev`는 작업 시작 시 HTTP 522를 반환했습니다. Cloud Environment 확인 결과 배포용 secrets/identity가 없고 Cloudflare 도구도 없습니다. GitHub 연결은 사용 가능하지만 기존 Cloudflare Pages 자동 배포 연결은 확인되지 않았습니다. 새로운 프로젝트를 만들거나 기존 프로젝트를 삭제하지 않았으며 TinyFish 유료 자동화/추가 결제도 실행하지 않았습니다.

`deploy/word-master-adventure-dist.zip`은 이번 빌드 결과로 갱신한 직접 업로드용 ZIP입니다. 기존 Cloudflare `english` → Deployments → Upload assets에서 업로드하면 주소를 유지할 수 있습니다. 업로드 완료 및 공개 URL 접속 확인 전에는 배포 완료로 보고하지 않습니다.
