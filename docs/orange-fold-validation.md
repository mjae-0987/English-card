# 오렌지 UI·음성·폴더블 대응

2026-10-27. 기존 Word Master Adventure를 수정했으며 프로젝트·학습 콘텐츠를 새로 만들지 않았습니다.

## 전체 읽기 진단과 변경

사용자는 폴드 Chrome에서 전체 읽기와 단어 발음이 모두 무음이라고 답했습니다. 단어도 무음이므로 문장 연결만의 문제라고 단정할 수 없습니다. 실제 폴드의 음성 엔진·미디어 볼륨·실행 중인 배포본은 원격으로 확인하지 못했습니다.

기존 코드를 추적한 결과 버튼은 현재 세트의 story 전체를 전달했고 빈 문자열/잘못된 필드/첫 문장만 전달하는 문제는 아니었습니다. 기존 재생기는 문장마다 utterance를 만들고 onend에서 다음 speak를 호출했습니다. 새 발화의 사용자 활성화에 의존하는 경로였고, 첫 발화 전에도 항상 cancel/resume을 호출했습니다. 이 경로들은 이번에 제거했습니다. 이것이 실제 폴드에서 발생한 무음의 확정 원인이라는 주장은 하지 않습니다.

실제 Chromium으로 기존 앱을 실행한 결과 getVoices()가 빈 배열이었고, 전체 읽기 클릭 후 재생 오류가 표시됐습니다. 수정 후 네이티브 검사에서도 영어 음성이 없고 재생 오류가 발생했습니다. **이 환경에서 실제 영어 소리 출력은 검증하지 못했으며 음성 문제 해결 완료로 판정하지 않습니다.**

현재 구현:

- 단어와 이야기의 공통 SpeechPlayer. 전체 이야기를 수정하지 않은 하나의 SpeechSynthesisUtterance로 전달합니다. 한글은 전달하지 않습니다.
- 첫 요청은 사용자 클릭 안에서 speak합니다. idle일 때 불필요한 cancel을 호출하지 않고, paused 상태에서만 resume합니다.
- 재생 중에는 다시 누르면 중지, 다른 단어/이야기를 누르면 이전 요청 취소 후 교체, 끝나면 idle로 복귀합니다.
- 요청 식별자로 오래된 종료·오류·음성 로딩 이벤트를 무시합니다. 화면/세트/pagehide/소유 컴포넌트 정리 시 중지합니다.
- 영어만 선택하고 en-US와 자연스러운 영어 음성을 우선합니다. 특정 음성 이름이 없어도 작동합니다.
- getVoices/voiceschanged 및 초기 목록 재확인. 기기 언어만 먼저 보이는 경우 최대 1.5초 동안 영어 로딩을 기다립니다. 대기는 취소할 수 있으며 다음 클릭을 영구 차단하지 않습니다.
- 0.75/1/1.15 속도와 음성 선택은 기존 speech:v1 키를 유지합니다. 실제 오류 시 짧은 메시지만 보여 줍니다.

무료 대체 재생 수단도 확인했지만 이 환경에는 로컬 TTS 엔진이 설치되어 있지 않았습니다. 유료 TTS, 비공식 외부 음성 API, 키 노출 또는 추가 설치를 도입하지 않았습니다.

## 디자인과 테마

요청한 기본 토큰 #FFF9ED / #FFFFFF / #FF7900 / #F45B00 / #FFE3B8 / #FFD45C / #2C241D / #786C61를 사용합니다. 기존 CSS의 초록 계열 색을 테마 변수로 치환했고 노드·진행률·완료·아이콘·선택 상태·팝업·복습을 오렌지/노랑으로 통일했습니다. 마스코트 사진의 초록 단어책은 원본 이미지를 보존하기 위해 수정하지 않았습니다.

설정에 햇살 오렌지/피치 크림/샌드 오렌지를 제공합니다. 별도 theme:v1 키에 저장하고 초기 HTML에서도 복원해 색 전환 시 깜박임을 줄입니다. 기존 학습 키는 변경하지 않습니다.

뜻 팝업은 단어·뜻·원래 이야기·번역·단어 발음·별표를 제공합니다. 바깥 클릭/Escape/닫기 버튼으로 닫고 이전 포커스를 복원합니다. 팝업 조작으로 세트 완료 기록을 변경하지 않습니다. 레오 이미지는 기존 gecko-mascot.jpg 그대로 사용합니다.

## 화면 구조

물리 해상도·기기명·user-agent로 레이아웃을 결정하지 않습니다. CSS viewport 760px을 기준으로 같은 컴포넌트를 1열/2열 배치합니다.

- 지도: 좁은 화면은 기존 세로 지그재그 지도, 넓은 화면은 지도/레오 + DAY 목록/진도/시작 버튼.
- 예문: 이야기/해석/전체 읽기/속도/학습 버튼 + 단어/발음/레오.
- 퍼즐: 정사각형 격자 + 입력/화면 키보드/가로·세로 힌트/채점.
- 단어장/오답/별표: 넓은 화면에서 단어 선택 목록 + 선택한 단어 카드. 너비 변경 때 카드를 다시 마운트하지 않습니다.
- 최대 앱 너비 1120px. 100dvh, safe area, 고정 하단 메뉴, 모션 감소와 회전을 고려합니다.
- 화면 키보드가 기본이고 실제 입력창의 inputMode는 none입니다. 기기 키보드로 전환하면 DOM을 먼저 갱신한 뒤 사용자 클릭 안에서 다시 포커스합니다. 물리 키보드·붙여넣기·Backspace를 유지합니다.
- 긴 이야기는 카드 내부 스크롤, 긴 힌트/단어/DAY 목록은 각 영역 스크롤입니다. 짧은 화면에서는 페이지 스크롤도 허용합니다.
- standalone 표시용 manifest를 추가했습니다. 브라우저 UI를 강제로 숨기지 않으며 오프라인 캐시/PWA 완전 오프라인 동작을 주장하지 않습니다.

## 보존

기존 src/data 아래 모든 파일(200단어·뜻·40세트)과 마스코트 SHA-256을 작업 전후 비교해 모두 같음을 확인했습니다. 기존 예문/퍼즐/오답/별표/완료 키와 형식을 유지합니다. 추가 view:v1 키에 선택 단어/칸·해석 표시·입력 모드를 저장하며 기존 퍼즐 임시 입력과 힌트/완료 이력을 초기화하지 않습니다. 화면 너비 변경은 CSS 배치만 바꾸며 현재 세트·입력·별표·힌트를 유지합니다.

## 검증 결과와 한계

- npm run build: TypeScript/Vite 프로덕션 빌드 통과. 기존 설치된 의존성을 사용했습니다.
- npm test: 원래 진행/퍼즐 검사와 DAY 01~05 데이터/500개 퍼즐/저장/잠금/별표/복습 검사 및 음성 로직 검사 통과.
- npm run test:render: 40세트·5개 완료 화면·200단어 카드·별표/복습/설정 렌더링 통과.
- 실제 Chromium 브라우저에서 320/360/390/430/600/768/900/1024/1280px의 9화면, 총 81조합 검사 통과. 가로 넘침/화면 밖 조작 버튼 없음, 1/2열 전환 및 정사각형 퍼즐 확인.
- 320×640부터 1280×800 및 900×500 회전을 포함한 50개 추가 화면 검사. 테마 강조색에 초록 계열 없음. 조정 후 360×800/390×844/768×850/900×900 등에서 주요 읽기 버튼이 하단 메뉴 위에 들어오는 것을 확인했습니다.
- 브라우저 UI로 DAY 01~05 각각 8세트 완료, 각 DAY만 사용하는 퍼즐 생성/입력/화면 키/Backspace/힌트/채점/완료/새로고침을 확인했습니다.
- 320px 브라우저 에뮬레이션에서 생성된 퍼즐의 71개 입력 칸을 모두 클릭해 선택 가능함을 확인했습니다. 실제 터치 이벤트나 실기기 검사는 아닙니다. 화면/기기 키보드 전환과 물리 입력, 회전 후 임시 입력/선택 위치 보존도 통과했습니다.
- 오답 실패/성공, 별표 독립 등록/해제, 3테마 새로고침 복원, 팝업 외부 클릭, 세트/팝업/퍼즐/복습 입력의 너비 전환 후 유지 확인.
- 음성의 정확한 전체 영어 텍스트 단일 전달, 중지/재시작/끝/단어 전환/연속 클릭/속도/리렌더 취소 없음은 브라우저에서 제어 가능한 합성기 대역으로 검증했습니다. 실제 음성 소리 검사가 아닙니다.

검증 엔진은 Chromium입니다. **일반 스마트폰·폴드8 전면·폴드8 내부의 실제 하드웨어, Android OS 소프트 키보드, Safari 및 실제 소리 출력은 미검증**입니다. 반응형 에뮬레이션 결과를 폴드8 실기기 검증 완료로 표시하지 않습니다. 브라우저 검사 원본은 orange-fold-validation.json, 재실행 도구는 scripts/browser-check.mjs입니다. 이 도구는 이미 설치된 Playwright/Chromium이 필요하며 WMA_PLAYWRIGHT_PATH/WMA_CHROMIUM_PATH/WMA_QA_DIR로 경로를 지정할 수 있습니다. 프로덕션 의존성에 브라우저 도구를 추가하지 않았습니다.
