# DAY 01 퍼즐 및 배포 상태

## 구현

퍼즐 코어는 외부 라이브러리 없이 `src/puzzle/`에 분리했습니다.

- `engine.ts`: 단어 선택, 교차 배치, 번호·경계 정리, 단어/전체 채점, 독립적인 구조 검증 및 예문 빈칸 생성
- `input.ts`: 입력·붙여넣기·Backspace의 순수 함수. 교차 칸은 좌표 키 하나로 공유
- `progress.ts`: 현재 시도와 완료 기록, 원본을 대조하는 저장값 파싱, 완료 검사
- `data.ts`: 기존 DAY 01의 원본 ID, 학습용 뜻과 이야기 연결
- `components/CrosswordGame.tsx` / `.css`: 모바일 입력·방향 전환·힌트·채점·축하 화면

한 번의 생성은 최대 20회 시도합니다. 모든 추가 단어는 이미 있는 단어와 교차하고, 같은 방향의 겹침, 시작/끝의 연속 글자, 새 글자의 옆 방향 인접 칸을 금지합니다. 배치 시 15×15 경계 제한을 적용합니다. 10~13개를 목표로 하며 10개 이상인 가독성 좋은 결과를 우선하고, 실패 시 8개 이상인 최선의 결과를 사용합니다. 생성 작업은 무한 재시도하지 않습니다.

영어 힌트는 해당 단어가 등장하는 기존 이야기 문장에서 해당 단어를 대소문자 구분 없이 모두 `________`로 치환합니다. 한글 뜻은 요청 시에만 공개하고 두 번째 요청에서 글자 하나를 공개합니다. 단어의 뜻이나 발음을 정답 대신 기본 힌트에 노출하지 않습니다.

채점으로 맞은 단어는 초록색, 다시 도전할 단어는 분홍색으로 표시합니다. 오답 채점은 정답 글자를 채워 넣지 않습니다. 글자를 수정하면 관련 가로·세로 단어의 채점 표시를 해제합니다. 빈 단어와 글자가 있으나 틀린 단어를 구분합니다.

## 모바일 입력

격자 칸은 화면 너비에 맞춰 자동 축소합니다. 일반 조작 버튼과 영어 편집 입력창은 44px 이상이며, 작은 격자 셀 대신 큰 입력창에서도 현재 위치를 편집할 수 있습니다. 영어 키보드를 위한 `inputMode=text`, `lang=en`, 자동 수정/맞춤법 비활성화를 적용합니다. 입력창의 글꼴은 22px로 iPhone의 입력 확대를 피합니다.

키 입력은 영어로 정규화해 다음 칸으로 이동합니다. 물리 키보드의 `keydown` 및 모바일의 네이티브 `beforeinput(deleteContentBackward)`를 지원하고, 한 번의 삭제가 중복 적용되지 않도록 기본 이벤트를 취소합니다. IME 조합 중에는 확정 전 내용을 입력하지 않습니다. 현재 단어와 문장 힌트, 큰 입력창을 sticky 카드로 유지하고 visualViewport가 변하면 편집 카드를 보이게 스크롤합니다. 하단 메뉴를 위한 기존 Safe Area 여백을 유지합니다.

## 기록

localStorage 키는 `word-master-adventure:day01-puzzle:v1`입니다. 예문 기록 키는 그대로 유지합니다.

- `active`: 퍼즐 구조, 칸별 입력, 단어별 힌트 단계, 공개한 글자의 위치, 힌트 횟수, 틀린 단어 ID 목록, 완료 시각
- `completions`: 퍼즐 ID별 완료 기록. 포함 단어, 틀린 단어, 힌트 횟수, ISO 완료 날짜를 보관

모든 정답을 코어에서 확인한 경우에만 완료 기록을 추가합니다. 같은 퍼즐을 중복 채점해도 완료 기록을 중복 저장하지 않습니다. 새 퍼즐은 `active`만 교체하고 이전 완료 기록을 보존합니다. 한 번 완료한 DAY 01은 새로운 미완료 퍼즐을 시작해도 완료 상태를 유지합니다. 저장 공간/권한 오류 시 메모리로 학습을 이어가며 새로고침 후 기록이 유지된다고 보장하지 않고 저장 재시도 버튼을 제공합니다.

## 실행한 검증

```bash
node --experimental-strip-types scripts/crossword.test.mjs
node --experimental-strip-types scripts/day01-progress.test.mjs
python3 scripts/validate-day01-lessons.py
python3 scripts/validate-vocabulary.py
```

퍼즐 테스트 8개 통과:

1. 100개 시드에서 연결·양방향·교차·중복·인접·번호·가장자리 확인. 독립적으로 격자의 모든 연속 문자열을 열거하여 등록한 단어와 대조
2. 40개 기본 힌트에서 정답 단어가 남아 있지 않음
3. 입력·덮어쓰기·붙여넣기·Backspace 및 교차 칸 공유
4. 채점의 불변성, 오답/빈칸으로 완료되지 않음, 전체 정답 판정
5. 완료 날짜·틀린 단어·힌트 사용 횟수의 저장 후 복원 및 새 퍼즐 생성 시 기록 보존
6. 부분 입력과 힌트 상태 복원, 손상된 격자·원본 불일치 저장 데이터 거부
7. 부적합 단어 및 생성 실패의 제한된 종료
8. 힌트의 단계 순서, 두 번째 단계에서 정확히 한 글자 공개, 최대 두 번 제한

100개 시드에서 단어 수는 10개 31회, 11개 31회, 12개 20회, 13개 18회였습니다. 예문 기록 테스트 5개와 원본/학습 콘텐츠 검증도 통과했습니다.

이 테스트는 순수 로직과 Storage 대역을 사용합니다. 브라우저 키보드 이벤트와 실제 localStorage, 음성 재생, 모바일 화면의 실제 동작 검증을 대신하지 않습니다.

## GitHub 및 Cloudflare 연결

GitHub 연결에서 사용자 `mjae-0987`은 확인했습니다. 처음 요청한 `word-master-adventure` 저장소는 조회되지 않아, 사용자가 지정한 `mjae-0987/English-card` 저장소를 사용합니다. 대상은 비어 있는 공개 저장소이며 쓰기 권한을 확인했습니다. 기존의 다른 저장소는 변경하지 않습니다. 저장소: https://github.com/mjae-0987/English-card

첫 파일 업로드는 `403 Resource not accessible by integration`으로 거부됐습니다. 앱 설치가 선택한 저장소에만 접근하도록 설정되어 있고, 해당 설치의 허용 저장소 목록에 `English-card`가 없음을 확인했습니다. 사용자에게 https://github.com/settings/installations/170545291 에서 `English-card` 접근을 추가하도록 요청했습니다. 계정의 관리자/쓰기 권한과 GitHub 앱의 저장소 접근 권한은 별개입니다. 권한이 바뀌기 전에는 같은 업로드를 반복하지 않습니다.

이후 사용자가 접근 허용을 추가했고, 허용 저장소 목록에 `English-card`가 포함된 것을 확인했습니다. 초기 README 커밋을 성공적으로 생성했으며 이 저장소를 기준으로 전체 소스와 원본 이미지를 업로드합니다.

필요한 사용자 작업:

1. GitHub 대상 저장소와 권한 지정은 완료했습니다.
2. GitHub 업로드가 확인된 후 Cloudflare Pages에서 `English-card` 저장소를 연결하거나, 현재 환경에 Cloudflare 배포용 보안 계정 연결을 추가합니다. 사용자는 Cloudflare 연결을 추가하겠다고 응답했으며 실제 연결 준비 여부를 별도로 확인해야 합니다.
3. 토큰·비밀번호를 채팅이나 프로젝트 파일에 넣지 않습니다.

Cloudflare 전용 연결 도구는 현재 제공되지 않으며 플러그인 검색에서도 Cloudflare 연결을 찾지 못했습니다. 관리 환경의 연결 상태에도 Cloudflare 자격 증명이 없습니다. 따라서 Cloudflare 리소스를 생성하거나 배포했다고 표시하지 않았습니다.

## 빌드 및 공개 후 확인 절차

현재 프로젝트 의존성과 사용 가능한 npm 캐시가 없어 빌드를 실행하지 못했습니다. npm 설치를 반복하지 않았으며 lockfile을 임의 작성하지 않았습니다. Node 22 설정과 기존 Vite/TypeScript/React 의존성 선언을 유지하고 `dist` 정적 빌드를 구성했습니다.

Cloudflare Pages에서 다음으로 빌드합니다: Framework `Vite`, Build `npm run build`, Output `dist`, Node `22` (22.12 이상). 루트에 package.json이 있으므로 Root directory는 저장소 루트입니다. 해시 기반 경로를 사용하므로 모든 앱 화면은 루트 문서에서 열립니다.

공개 배포가 성공한 뒤 확인해야 할 항목:

- 실제 배포 응답에 나온 URL이 HTTPS로 정상 접속되는지
- 320/375/390/430px에서 가로 스크롤, 하단 메뉴 겹침, 잘림이 없는지
- 지도 50일/100노드, 게코 원본 이미지, 하단 4개 메뉴
- 예문 8세트, 단어 뜻, 해석 전환, 단어/전체 발음, 새로고침 후 예문 완료 기록
- 예문 완료 전 퍼즐 잠금 및 8세트 완료 후 해제
- 퍼즐 격자 선택·교차 방향·영어 키보드 입력·자동 이동·Backspace
- 두 단계 힌트, 단어/전체 채점, 오답 수정, 전체 정답 축하
- 완료/오답/힌트/날짜 및 부분 입력의 새로고침 후 복원, 새 퍼즐에서 이전 완료 기록 유지
- Android Chrome 및 iPhone Safari의 실제 키보드와 Web Speech 재생

아직 실제 공개 URL, 브라우저 에뮬레이션 결과, Android/iPhone 실기기 검증 결과는 없습니다. 배포 성공이나 실제 모바일 정상 동작이 확인된 것으로 보고하지 않습니다.
